SITEBORNE A2A x402 extension v1

Extension URI: https://siteborne.net/extensions/a2a/x402/v1. It binds A2A skill selection to SITEBORNE's x402 paid-service resources. It is declared with required: false.

Parameters

  • x402Version — the x402 protocol version.
  • paymentRequiredForUsefulExecution — true: useful execution requires payment.
  • productionEnabled — true when at least one listed service is production-callable.
  • services[] — per skill: serviceId, serviceVersion, scheme, resource, inputSchemaUri, outputSchemaUri, declaredLimitations, productionEnabled, and economics.

economics

The canonical economic contract for the service: scheme, pricing_model, price_unit, list_amount (exact) or authorization_maximum and tier_prices (upto), actual_settlement_model, limits, modes (each with price_defined and capability_available), available_modes, release_posture, production_enabled, payment (network, asset, pay_to; null when not configured) and pricing_source_version. Amounts are decimal USD strings.

For an upto service the payment challenge authorizes authorization_maximum; the charge is measured usage and never exceeds it.
