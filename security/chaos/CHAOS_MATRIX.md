# SUN-1000 Checkpoint 1N-A — v2 Deterministic Chaos Matrix

Machine-readable-enough index of every scenario in
`apps/edge-api/tests/chaos-v2.test.ts`, executed by `pnpm security:chaos`
(`scripts/security/run-chaos.ts`). Every scenario is a named, deterministic
`it()` block — no random fault probabilities. `run-chaos.ts` fails closed unless
every row below both ran and passed, not merely that the overall process
exited 0.

Target: the forward v2 service family exclusively (`company_evidence_graph.v2`,
`web_context_verified.v2`, `document_evidence_json.v2`,
`verify_agent_output.v2`) and their real `/v2/...` HTTP routes. Credential-free
throughout: every fault is injected at the `PaymentEvidenceProvider`/executor
seam `paid-services.ts` already exposes — zero Nevermined calls, zero CDP calls,
zero live settlements.
